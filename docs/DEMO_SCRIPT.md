# Demo Video Script (≈ 3 min)

## 00:00 — Hook (10s)
> "Meet Sales Copilot — an AI voice chatbot your team can actually talk to. Built for production, deployed today."

## 00:10 — Sign in (20s)
- Open https://conversly-app.lovable.app
- Click **Continue with Google** → land in `/chat`
- Narration: "Google OAuth, email/password, and full session persistence out of the box."

## 00:30 — Text chat (30s)
- Type: _"Give me a 30-second pitch for a CRM for solo founders."_
- Show the reply streaming in with typing indicator.
- Narration: "Powered by Google Gemini via a Node backend on Render — the API key never touches the browser."

## 01:00 — Voice input + output (40s)
- Click 🎙️ mic → say: _"What's a good follow-up email if they ghost me?"_
- Transcript appears; assistant replies AND speaks aloud.
- Click **Stop Speaking** to interrupt.
- Narration: "Browser-native Web Speech API — no third-party STT/TTS bills."

## 01:40 — Conversation memory (20s)
- Ask: _"Rewrite that in a more casual tone."_
- Show that context is preserved.

## 02:00 — History management (25s)
- Rename thread to "Cold outreach playbook".
- Search the sidebar for "cold".
- Delete a thread with the confirmation dialog.

## 02:25 — Admin dashboard (25s)
- Sign in as admin → click **Admin** in sidebar.
- Walk through metrics: total users, messages, recent activity.

## 02:50 — Wrap (10s)
> "Voice, memory, RBAC, admin — production-ready in one repo. Star it on GitHub."
